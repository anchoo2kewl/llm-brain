# Brain Hub desktop 0.1.4

- **Arrange terminals without restarting them.** Focus or move a terminal left, right, up, or down. Resize adjacent panes, restore balanced splits, and hide the sidebar when you need more space. On macOS, find the controls in the Terminal menu. On Linux, open Actions in the hub workspace.
- **End a session from its row.** Hover over the session and click × to end its CLI process on its machine. The × also appears on keyboard focus and names the session for screen readers; on macOS, VoiceOver offers End Terminal on the row. To keep a job running, close its pane instead.
- **Move a conversation to another machine.** Drag a terminal onto another machine in the sidebar (on macOS, or right-click → Move to Machine; in the workspace, Actions → Move focused terminal to). The hub does the move and the row shows each step: check readiness, export, copy, resume, check it is live, end the source. The old terminal ends only after the new one is running, and a failure earlier leaves it as it was. The destination then owns the conversation, so the laptop can go offline. Only the conversation moves: commit and push uncommitted work first, and a folder that is not on the destination runs in its home folder. See "End or move a terminal" in docs/desktop-app.md.
- **Keep Brain Hub up to date.** At startup, the app checks for a stable desktop release. A writable macOS installation or Linux AppImage can install the update for the next launch. Use Check for Updates for a manual check or switch off Automatically Install Updates in the application menu. Linux deb and rpm users install new versions through their package installer.

Users upgrading from 0.1.3 or earlier need to download the desktop client once to receive the updater. Linux workspace controls, the workspace ×, and moving terminals need an updated hub; an older hub says so instead of moving.
