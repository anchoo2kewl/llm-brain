# Brain Hub desktop 0.1.17

- **Move a session between hubs.** Move now works from one hub to another, for example from the Studio to the laptop. The destination hub copies and resumes the conversation, and checks that it runs. Then the source session ends. It needs hub 0.1.17 or later on both hubs.

Builds: native universal macOS app, Linux (AppImage, deb, rpm) and Windows (msi, exe) desktop packages.
