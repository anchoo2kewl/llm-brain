# Brain Hub desktop 0.1.5

- **Drag a terminal to another machine.** Drag its sidebar row, or the ⠿ grip at a pane's top corner, onto a machine. You can drop it on the large machine tiles under the terminal list, on the machine's name, or among its terminals. Right-click the row or the grip and choose **Move to Machine** to do the same from a menu. In 0.1.4, a drag only worked when dropped on the small machine header, and that header often missed it. The web workspace has the same pane grip and larger machine targets.
- **Clone instead of move.** Hold ⌥ (Alt) as you drop, or choose **Clone to Machine**. A clone starts a new conversation on the destination with all of the source's context, and the source keeps running. A move still ends the source only after the destination is checked to be live. The row and the pane grip show each phase as it happens.
- **Compatible provider required.** The hub moves or clones only to a machine that has the same CLI: Claude Code for a Claude conversation, Codex for a Codex one. That CLI must be logged in. A move right after a turn now waits for the conversation to reach the hub, instead of failing with "no conversation yet". Uncommitted files, worktrees and running processes stay on the source machine.
- **Control Brain Hub from any MCP client.** The app includes `brain-mcp`, a stdio MCP server, and **Settings → MCP** shows ready-to-paste setup for Claude Code, Codex, and clients that use `mcpServers` JSON. Its tools list hubs and sessions, read and send to sessions, rename, end, move or clone a session and follow its progress, and open, focus, lay out or zoom the workspace. A session's id always goes to the hub that listed it. The local `desktop_update` tool reports, checks or installs the verified desktop update. See docs/mcp.md. The tool needs python3.
- The Mac sidebar and move menus use the names you saved in Hubs.

Moving, cloning and workspace control need the matching hub update. An older hub says so instead of moving. On the Mac, the app applies open, focus and zoom requests from an MCP client; layout requests apply to the web workspace.
