# Brain Hub desktop 0.1.11

- Settings → Memory sets, replaces or removes the TaskAI API key that turns shared memory on, on one hub or on every hub at once, and shows whether memory is on for each. The hub checks the key with TaskAI before saving it; the app keeps no copy, and the key is never shown after saving.
- Needs hub 0.1.10 or later; an older hub says so.

Builds: native universal macOS app and Linux desktop packages.
